zTerm

启动：在应用菜单搜索“zTerm”。
命令行：~/.local/bin/zterm
旧命令 ssh-workbench 仍可使用，原有服务器列表和外观配置继续保留。

标题栏右上角“设置”包含“添加服务器”“导入别名”“快捷键”“外观设置”“订阅额度”。
“设置 → 添加服务器”保存 SSH 别名，例如 dev-server。
“设置 → 导入别名”读取 ~/.ssh/config 中明确的 Host 别名及 Include 文件。
通配符规则不作为服务器导入，配置本身仍由 OpenSSH 完整解释。
点击左侧服务器建立第一个会话；最后一个会话标签紧邻的“+”创建独立连接。
标签按 [1] [2] + 顺序排列；标签过多时可横向滚动。
每个标签加宽显示，序号与右侧“×”关闭按钮位于同一个标签内，减少误触。
标签显示为 [1]、[2] 等序号。窗口标题显示当前服务器 IP 或 SSH 别名，随服务器切换。
本地会话标题为“本地终端”，欢迎页标题为“zTerm”。
标题栏左侧按钮可收起/展开服务器栏，收起时保持现有连接。
切换服务器时，之前打开的会话会继续运行。标签可拖动排序。
会话结束后保留输出，可以点击“重新连接”。
底部统一为一栏：左侧显示当前服务器及“在线”状态，离线时显示可点击的“重新连接”；
本地会话结束时显示“重新打开”。状态随当前标签切换，悬停可查看退出码或启动失败原因。
“移除服务器”仅移除工作台保存的别名，不修改 SSH 配置。
关闭活动会话、服务器或窗口时会提示确认。
重启工作台会保留服务器列表，但不会自动恢复 SSH 连接。

外观设置：
“界面主题”控制 zTerm 的标题栏、服务器侧栏、会话标签、底栏、菜单和应用对话框。
默认“跟随终端配色”，自动搭配所选终端预设；也可独立选择 14 套配色或“跟随系统外观”。
界面使用协调的背景、层次色和强调色；终端自定义文字/背景色不会改变界面主题。
选择时实时预览界面，“取消”或关闭设置窗口恢复原样，“保存并应用”后重启仍保留。
点击“设置 → 外观设置”，在“字体与字号”中选择已安装的字体、字形和大小。
支持浅黄背景黑字、白底黑字、黑底灰字、黑底白字、黑底绿字、Ubuntu 默认（李子色），
配色依据 Ubuntu 24.04 的 GNOME Terminal / Yaru，使用其默认 ANSI 16 色。
保留 Solarized、Gruvbox、PaperColor、Peaksea 各自的 Light / Dark 配色，共 14 套主题。
新配置默认使用 Ubuntu 默认（李子色）。经典紫、深色、浅色、深海蓝已移除，旧配置自动兼容迁移，
字体与自定义颜色保留；读取不改写配置文件，在保存外观后写入新主题标识。
也可分别设置文字、背景和光标颜色。来源与适配说明见 THEME_SOURCES.txt。
切换主题会恢复该主题的预设颜色；之后可以继续自定义颜色。
对话框下方实时预览。“保存并应用”同时更新所有会话并保存设置，新会话和重启后均沿用。
“取消”不改变会话或已保存配置；“恢复默认”先更新预览，保存后才生效。
保存外观会将各会话的临时字体缩放重置为 100%；之后仍可用快捷键缩放。
“终端配色”改变终端内容区；“界面主题”独立控制应用外观。外观配置与服务器列表分别保存。

SSH 连接使用 /usr/bin/ssh，用户名、密钥、端口、跳板机等均遵循
系统 SSH 配置。密码和首次连接的主机确认直接在终端内处理。
本应用不保存密码。若尚未定义别名，可自行在 ~/.ssh/config 添加：

Host dev-server
    HostName 192.0.2.10
    User your-user

别名列表：${XDG_CONFIG_HOME:-~/.config}/ssh-workbench/servers.json
外观配置：${XDG_CONFIG_HOME:-~/.config}/ssh-workbench/appearance.json
程序文件：${XDG_DATA_HOME:-~/.local/share}/ssh-workbench/

快捷键：
Ctrl+Shift+T             新会话
Ctrl+Shift+W             关闭当前会话
Ctrl+Shift+C / V         复制 / 粘贴
Alt+1 … 9               按位置切换标签
Ctrl+PageUp / PageDown   前后切换标签
Ctrl+加号 / 减号 / 0     放大 / 缩小 / 重置字体

订阅额度：
统一底栏中间显示当前机器 Codex 的已用比例和重置时间，切换服务器随之更新。
查询在后台进行，每 5 分钟自动刷新；右侧 ↻ 可手动刷新，悬停查看数据时间。
重置时间使用工作台所在机器的时区；已到重置时间的旧数据标记“待刷新”。
远端需 Python 3.9+，SSH 使用 BatchMode，需要密钥/agent 等免交互登录。
只使用密码登录的终端会话仍可正常工作，但独立的后台额度查询可能无法登录。
Codex：服务器需安装 codex CLI 并使用订阅账号登录；仅调用官方额度读取接口。
未返回数据、未登录、网络失败均显示具体状态，不将缺失数据显示为 0%。
额度仅覆盖官方提供的 Codex 主额度/次额度，不代表模型专属额度或 API 余额。
工作台不读取或传输登录凭据，不会修改远端 CLI 配置。

开发验证：
/usr/bin/python3 -m py_compile app.py model.py quota.py test_workbench.py test_quota.py
/usr/bin/python3 test_quota.py
GDK_BACKEND=x11 xvfb-run -a /usr/bin/python3 test_workbench.py

依赖：python3-gi、gir1.2-gtk-3.0、gir1.2-vte-2.91、openssh-client。
运行方式采用 GNOME VTE spawn_async：
https://gnome.pages.gitlab.gnome.org/vte/gtk3/method.Terminal.spawn_async.html

卸载：删除 ~/.local/bin/zterm 和 ~/.local/bin/ssh-workbench、应用数据目录 ssh-workbench/
和 applications/local.ssh.Workbench.desktop。别名配置可按需保留。
专属图标位于 ${XDG_DATA_HOME:-~/.local/share}/icons/hicolor/scalable/apps/local.ssh.Workbench.svg。
